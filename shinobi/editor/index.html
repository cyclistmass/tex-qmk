TEX Shinobi keymap editor

For the open-source QMK firmware. Remap keys on every layer, then download a firmware image to flash. Everything happens in this page; nothing is uploaded.

1. Firmware image

The editor writes your keymap into a released image, and only into its keymap and macro bytes. It accepts ; macros and mouse keys need or later. Download the image from the releases page, then load it here.

2. Keymap

The keyboard sends key positions and the computer's layout turns them into characters, so the keys below show what they type on that layout (as Windows lays it out), and macros (step 4) are typed for it. Fn+B and the other typed answers always type as on a US layout.

4. Macros

A macro key types a short sequence: assign Macro 0-Macro 15 to keys in step 3, and write what each one types here. Plain text is typed for the layout chosen in step 2, and a character it can't type is marked. {Enter}, {Tab}, {F5}, {Del} name a key; {Ctrl+C} or {Win+R} hold modifiers for it; {{ types a {. 5. Mouse keys

The Mouse movement keys in step 3 move the pointer while held, in eight directions, speeding up the longer they are held. They work alongside the TrackPoint and its buttons.

Also new in v1.1, set with the DIP switches on the bottom (no editing needed):

  • DIP 4 on: hold Fn and move the TrackPoint to scroll; a tap of Fn alone is a middle click.
  • DIP 5 on: reverses vertical scrolling.

6. Save and build

Flash the downloaded image like a release, with the keyboard on USB and the PC's Bluetooth off:


  
or wrap it into TEX's updater: python -I build_updater.py AP_0407_4.04.exe <image> out\ and run the result with -force. Both tools are in shinobi/tools. Hold Esc while plugging in to reach the bootloader if anything goes wrong.

  
keymap.c is for building it yourself: put it in shinobi/qmk/keymaps/<name>/ and run shinobi/tools/build_firmware.sh. The downloaded image is byte-for-byte what that build gives when the keymap is named default and built with the release's date (shinobi/editor/test/byte_identity.sh).
